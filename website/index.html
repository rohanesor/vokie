WHAT VOKIE IS

Built for the moment
ordinary networks stop.

01

OFFLINE-FIRST

The communication foundation is designed to operate without a backend or cloud connection.

02

BLUETOOTH

Real Vokie peer discovery, RFCOMM transport, acknowledgement, Room persistence, offline queue, retry, and duplicate protection are implemented.

03

LOCAL PROCESSING

Offline multilingual speech recognition with Whisper and offline text-to-speech with sherpa-onnx MMS run entirely on the device. No cloud speech or TTS services.

04

LOW-END READY

Clear controls, high contrast, and a restrained interface designed with low-memory phones in mind.

INSTALLATION

How to install

  1. Download the Vokie APK from this page.
  2. Open the downloaded APK.
  3. Allow installation from this source if Android asks.
  4. Install and open Vokie.
  5. Grant Nearby Devices permission when communication is initiated.
  6. Connect to another Vokie device.

Offline operation: This APK includes Whisper STT and English MMS-TTS. Other verified language voices are optional one-time Wi-Fi downloads; every installed voice works without internet afterwards.

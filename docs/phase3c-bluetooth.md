# Phase 3C Bluetooth RFCOMM

Existing Bluetooth Classic RFCOMM remains the current tested transport path. It preserves discovery, pairing, socket lifecycle, reconnect, Packet v2 fragmentation, reassembly, and ACK behavior. Packet serialization is not implemented by a transport.
